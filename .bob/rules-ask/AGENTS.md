# Documentation Context

- This is a personal IBM blog/portfolio, not a software application — there is no app code, no API, no database.
- The `README.md` and `index.markdown` contain largely the same content; `index.markdown` is the actual rendered home page.
- `_site/` is the generated output directory — never edit files there directly; they are overwritten on every build.
- No test, lint, or CI pipeline exists in this repo.
