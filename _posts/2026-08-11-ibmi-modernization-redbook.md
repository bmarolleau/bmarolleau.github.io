IBM Redbooks are the authoritative technical deep-dives of the IBM ecosystem — peer-reviewed, field-tested, and built from real customer engagements. This one covers exactly what I do every day: taking decades of IBM i RPG and COBOL code, and making it legible, testable, and evolvable using AI.

I contributed to this Redbook alongside IBM colleagues and field engineers, drawing from the same customer projects and enablement sessions that underpin the posts on this blog. The content spans Bob-assisted code comprehension, RPGUnit test generation, DDS-to-DDL migration, REST API enablement with IWS, and Ansible Infrastructure as Code — a complete modernization playbook.

If you're an IBM i shop wondering where to start with AI-assisted modernization, this is the reference document. Free, publicly available, and grounded in real IBM i workloads.
