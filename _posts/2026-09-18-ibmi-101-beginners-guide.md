IBM i (formerly AS/400) is an integrated OS where the database is built *into* the OS — not a separate product. Every object is typed. Db2 for i is the filesystem. Systems run for years without a reboot. It's boring in the best possible way.

The `ibmi-101` lab takes a developer from zero to their first RPG program, SQL query, and IFS file operation in a few hours. It runs on any trial IBM i system. It's the starting point I use for every enablement session with developers who've never touched the platform.

Why learn it in 2026? IBM i skills are scarce, salaries are strong, and the modernization wave means there's a generation of work ahead. If you know both RPG and the cloud-native world, you're extremely valuable.
